# 🍔 FuegoBurger — Sitio web de restaurante

Sitio web estático para **FuegoBurger**, una hamburguesería *"de barrio pero elegante"*.
Proyecto de tema libre de HTML y CSS del bootcamp Full Stack de **Campuslands GT**.

## ✨ Secciones
- 🏠 **Inicio**: portada y menú destacado (La Clásica, La Bandida…).
- 🛎️ **Servicios** (`paginas/servicio.html`)
- 🍟 **Productos** (`paginas/productos.html`)
- 📞 **Contacto** (`paginas/contasto.html`)
- ⭐ Páginas extra: *La Estrellita* y *La W*
- 📱 Diseño responsive con menú móvil y favicon/manifest para web app.

## 🛠️ Tecnologías
HTML5 · CSS3

## 📂 Estructura
```
├── index.html        # Página principal
├── paginas/          # Páginas internas
├── css/              # Una hoja de estilos por página
├── imagenes/         # Imágenes y favicon
└── musica/           # Audio del sitio
```

## ▶️ Cómo verlo
```bash
git clone https://github.com/juanlema-16/proyecto_tema_libre_html.git
```
Abre `index.html` en el navegador o usa **Live Server** en VS Code.
